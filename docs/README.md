# Creating a Banking System with Python

Project developed as part of the "Potência Tech" Bootcamp, powered by iFood | Data Science, under the guidance of expert [Guilherme Carvalho](https://github.com/guicarvalho "Guilherme Carvalho").

## Backend

In this project, you will have the opportunity to create a banking system using Python. The goal is to implement three essential operations: deposits, withdrawals, and account statements. The system is designed for a bank looking to monetize its operations. Throughout this challenge, you will be able to apply your Python programming knowledge to build a functional system that simulates banking transactions. Get ready to sharpen your skills and demonstrate your ability to develop practical, efficient solutions.

## Frontend

A semantic, accessible, and responsive user interface prototype built with HTML5, CSS3, and modern vanilla JavaScript. This client application models the financial domain workflow logic from the core Python backend code implementation.

## Features

- **Dark & Light Interface Themes**: Dynamically shifts UI styles with specialized native vector design layout controls. Default state renders in Dark mode.
- **Multi-language Support (Internationalization)**: Completely shifts runtime translation strings between English (default), Portuguese, and Spanish profiles.
- **Semantic HTML5 & Accessible Structure**: Clean hierarchical sections reinforced with `aria-*` tags to sustain assistive accessibility interfaces.
- **Responsiveness**: Flexible structural flexbox layouts tailored seamlessly for monitors, viewport tablet matrices, or smartphone handheld screen sizes.

## Tecnologies used

- **Python**: The executable python script containing the core operational logic.
- **HTML**: The markup foundation with semantic boundaries.
- **CSS**: Layout orchestration variables handling dynamic switching structural themes.
- **JavaScript**: State management executing runtime computations.
